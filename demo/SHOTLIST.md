# Shotlist

Record the app first (browser 1280×720). HyperFrames composites type on top.
URLs use `/demo?beat=` prefills so nothing is typed on camera. Use the code the
`beat=2` run gives you for shots 3–4.

| # | Seconds | File | Notes |
| --- | --- | --- | --- |
| 1 | 0–8 | `capture/01-landing.webm` | `/` — hero + app frame, no scroll |
| 2 | 8–16 | `capture/02-start.webm` | `/demo?beat=2` → auto-routes to `/start` |
| 3 | 16–32 | `capture/03-meetup.webm` | `/m/[code]` — second tap lands, map fills |
| 4 | 32–58 | `capture/04-result.webm` | `/m/[code]/result` — play the deciding sequence untouched |
| 5 | 58–75 | `capture/05-moneyshot.webm` | `/` scrolled to the sample pick card |
| 6 | 75–90 | `capture/06-end.webm` | `/` still, footer CTA, or freeze last frame |

Cursor path if you record one take:

1. Open `/`
2. Click `Start a meetup` (navbar) or the hero CTA
3. On `/start`, click `Start a meetup` — copy the code from the result screen
4. Open `/demo?beat=3&code=[code]` to land the second phone
5. On the meetup screen, click `Find our spot`
6. Let the sequence play. Do not click — the pin drop is the money shot.

Do not scroll on shots 1–2. Shot 4 must not be cut mid-sequence.
